# 07. 気泡による白い濁り

冷凍庫で作った氷のように、 **芯を気泡で白く濁らせる**。 SDF が中身 (表面からの深さ) を持っていることを使う。

この段の絵: SDF の氷の真ん中が白く濁る。 B で気泡を抜くと、 澄んだ氷に戻る。

---

## 1. なぜ芯が白いか

水は外側 (容器に触れている所・空気に触れている所) から凍っていく。 水に溶けていた空気は氷に入りにくいので、 まだ凍っていない内側へ押しやられ、 **最後に凍る芯に小さな泡として閉じ込められる**。
泡 (空気) と氷は屈折率が違うので、 泡に当たった光はあらゆる向きへ散らばる (散乱)。 たくさんの泡で何度も散らばった光は色を失って白く見える。 雲や雪が白いのと同じ。

## 2. どこに泡を置くか (BubbleDensityAt)

SDF の値 $\phi$ は、 中では負で、 $-\phi$ が **表面までの深さ** になる。 これで 「芯だけ」 を選べる。

```hlsl
float BubbleDensityAt(float3 p, float depth)
{
    float core = smoothstep(0.10, 0.22, depth);
    float pattern = 0.55 + 0.45 * sin(p.x * 37.0) * sin(p.y * 41.0 + 1.7) * sin(p.z * 39.0 + 0.6);
    return BubbleDensity * core * pattern;
}
```

| 部品 | 意味 |
| --- | --- |
| `smoothstep(0.10, 0.22, depth)` | 深さ 10 cm より浅い所は 0、 22 cm より深い所は 1、 その間はなめらかに増える。 外側の澄んだ層と、 濁った芯の境目をぼかす |
| `pattern` | 正弦波を 3 つ掛けた模様 (0.1〜1)。 泡の濃さにむらを付け、 均一な霧に見えないようにする |
| `BubbleDensity` | 全体の濃さ (1/m)。 セッターで変える。 0 なら泡なし |

> メッシュは表面しか持たないので、 「表面から何 cm の深さか」 は分からない。 SDF だからこれが 1 回の読み出しで分かる。

## 3. 光の計算: 散乱と減衰

泡のある所を **光を散らす霧 (関与媒質)** と考える。 密度 $\sigma_s$ (1/m) の霧を長さ $s$ 進むとき:

- 泡に当たらずに通る割合: $e^{-\sigma_s s}$ (Beer–Lambert と同じ形)
- 泡に当たる割合: $a = 1 - e^{-\sigma_s s}$

当たった光は散らばり、 その一部が目の方へ来る。 逆に言えば、 **目の方へ進む光線の上の泡は、 周りから来た光を目の方へ散らばらせてくれる** (内向きの散乱)。

### 3.1 1 歩ごとに足す

`MarchInside` で中を進む 1 歩ごとに:

```hlsl
float a = 1.0 - exp(-BubbleDensityAt(q, -d) * s);
col += thr * exp(-Absorption * t) * (bubbleT * a) * BubbleLight();
bubbleT *= 1.0 - a;
```

| 掛けている物 | 意味 |
| --- | --- |
| `thr` | 氷に入るまでに残っている光の割合 (表面の反射の分などが抜けた残り) |
| `exp(-Absorption * t)` | 入口からこの点まで (長さ `t`) の、 氷の吸収 |
| `bubbleT` | 入口からこの点までの泡に遮られずに残っている割合 |
| `a` | この 1 歩で泡に当たる割合 |
| `BubbleLight()` | 泡を照らしている光の明るさ (次節) |

進み終えたら、 出口までの全部の長さで吸収し、 泡に遮られた分も減らす。

```hlsl
thr *= exp(-Absorption * t) * bubbleT;
```

奥の景色は泡に遮られて暗く (見えにくく) なり、 代わりに泡が散らばらせた白い光が見える。 これが 「濁り」。

### 3.2 泡を照らす光 (BubbleLight)

```hlsl
float3 BubbleLight()
{
    return SunColor() * 0.25 + float3(0.35, 0.42, 0.55);
}
```

本当は、 泡に届く光は 「表面で屈折して入ってきた空と太陽の光」 で、 それも周りの泡で散らばって弱まっている。 正しく求めるには、 泡の所から光源へ向けてもう一度光線を追う必要がある (重い)。
ここでは **周りからぼんやり届く一定の光** とみなす近似にした: 太陽の 1/4 と、 空の少し青い光。

### 3.3 近似のまとめ

| 近似 | 本当は | 見た目への影響 |
| --- | --- | --- |
| 泡を照らす光は一定 | 場所によって違う (太陽の側が明るい) | 濁りが全体に同じ明るさ |
| 散らばる向きは考えない | 泡の散乱は前の方へ強い | 逆光でも順光でも同じように白い |
| 1 回だけ散らばる | 何度も散らばる | 濃い所の白さの出方が少し違う |

## 4. 確かめ方

| 項目 | どうなればよいか |
| --- | --- |
| 芯 | 真ん中が白く濁り、 外側 (表面から 10 cm くらい) は澄んでいる |
| むら | 濁りに筋やむらがある (均一な霧でない) |
| 奥 | 芯の向こうの床が見えにくい |
| 切り替え | B で泡を抜くと、 澄んだ氷になる |

## 5. つまずきやすい所

| 症状 | 原因と直し方 |
| --- | --- |
| 全体が白くなる | 深さの範囲 (`smoothstep`) の端が逆、 または 0 から始まっている |
| 濁りが縞々になる | 1 歩が大きすぎる (上限 5 cm を下げる) / 模様の周波数が高すぎる |
| 濁りが暗い・灰色 | `BubbleLight` が弱い / 吸収を 2 回掛けている |
| 泡の所だけ明るすぎる | 散乱に `bubbleT` (手前の泡で遮られた分) を掛け忘れ |
