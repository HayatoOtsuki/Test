# step7. 色付きの影

**ゴール**: 氷の影が、 黒でなく **薄い青** で床に落ちる。 芯の気泡の所は少し濃い。

計算の解説: [`docs/08-ice-shadow.md`](../08-ice-shadow.md)。 見本: `src/ice/shaders/IceShadow.hlsl`。

---

## 1. 自分のエンジンの影の仕組みを調べる

| エンジンにある物 | やり方 |
| --- | --- |
| シャドウマップ (不透明な物の影) がある | 氷はシャドウマップに **深度を書かない** (書くと黒い影になる)。 下の 2. で、 氷の影を別に足す |
| 透過の影 (色付きのシャドウマップ) がある | 氷を、 その仕組みで 「通り抜ける割合」 を書く物として登録する。 割合は下の 2. の式で求める |
| 影が無い | 下の 2.〜3. をそのまま使う |

## 2. 通り抜ける割合を SDF で求める

床の点 (影を受ける点) から **太陽の向き** (step1 のライトの向き) へ SDF を追い、 氷の中を通った長さと、 気泡の濃さの合計を数える。

```hlsl
float d = SampleSdf(q);
float s = max(abs(d), VoxelSize * 0.5);   // 外は φ、 中は −φ ずつ (表面を越えない)
if (d < 0.0) { insideLength += s; bubbleDepth += BubbleDensityAt(q, -d) * s; }
...
T = exp(-Absorption * insideLength - bubbleDepth) * 0.9;
```

- 赤がよく吸われるので、 影は青くなる。
- 0.9 は、 入るときと出るときの表面の反射の分などをまとめた近似。

## 3. 影を描く

このリポジトリのやり方 (影を受けるのが平らな床のとき):

1. 影が落ちうる床の四角形を作る。 箱の底面の四角と、 箱の上面を太陽の向きに沿って床へ落とした四角を、 両方含む四角 (見本: `ShadowQuadCorner`)。
2. 氷を描く **前に**、 その四角形を描く。 画素ごとに 2. の `T` を求め、 **太陽の光だけに `T` を掛けた床の色** を描き直す。 影が無い所 (`T ≈ 1`) は `discard`。
3. 氷を描く。

自分のエンジンで床の色の式が分からないときは、 簡単な近似として **掛け算のブレンド** (`dest × T`) で床を暗くしてもよい。 ただし:

- 空からの光 (アンビエント) まで減るので、 影が少し濃くなる。
- トーンマップの後の色に掛けると、 濃さの比がずれる。 できればトーンマップの前 (ライティングの段) で掛ける。

## 確かめ方

- [ ] 影が太陽と反対の側に落ちる。 ライトの向きを変えると影も回る
- [ ] 影が黒でなく薄い青。 吸収の色を変えると影の色も変わる
- [ ] 気泡があると影の真ん中が少し濃い
- [ ] 影の四角形の縁が見えない

## つまずきやすい所

| 症状 | 原因 |
| --- | --- |
| 影が真っ黒 | 氷がシャドウマップに深度を書いている / 空の光にまで `T` を掛けている |
| 影が逆の側 | ライトの向きの約束 (面から光源へ / 光が進む向き) が逆 |
| 影の先が切れる | 四角形が小さい (上面を床へ落とした所を含めていない) |
| 四角形の縁が見える | 描き直した床の色が、 周りの床とずれている (霧やトーンマップの順) |
