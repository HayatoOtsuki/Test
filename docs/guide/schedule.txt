SDF 氷を自分のプロジェクトに実装する進め方
============================================

今の状態 (ここから始める)
  - IceComponent / IceGenerate / IceImplement がある
  - キューブ・スフィア・円柱のプリミティブを作って mGeom に入れ、 切り替えて描ける (ジオメトリとパイプラインを作ってある)
  - シェーダーでマテリアル (基本色・メタリック・ラフネス・スペキュラ) を調整できる
  - カメラとディレクショナルライトの値は、 シェーダーにハードコードしている

進め方の約束
  - 1 段ずつ。 段の終わりで動かして確かめてからコミットする
  - 1 段で 1 つのことだけ変える (絵が壊れたとき、 原因がすぐ分かる)
  - 見本 (このリポジトリ) のコードは写さず、 読んで理解してから自分のエンジンに合わせて書く
  - 詳しい手順: docs/guide/stepN-*.md、 計算の解説: docs/0N-*.md
  - 段の前に、 その機能だけのサンプル (samples/0N_*) を動かして、 作る物を目で見ておく

0. 準備
  [ ] docs/DESIGN.md と docs/guide/README.md を読む (全体の形と用語)
  [ ] 自分のプロジェクトで作業用のブランチを切る
  [ ] RenderDoc か PIX で、 今のプロジェクトのフレームを取り込めるようにする

1. カメラとライトをシェーダーへ渡す (ハードコードをやめる)        step1-camera-light.md
  [ ] 既存のシェーダーの cbuffer と #include を読み、 カメラの行列がどこから来ているか探す
  [ ] C++ でその番号に何を結び付けているかをたどる (RenderDoc で中身も見る)
  [ ] 氷のシェーダーでも同じ定数を読む (無ければ IceImplement が自分の定数バッファを持つ)
  [ ] ライトの向きと色をハードコードから定数に置き換える
  [ ] 確かめる: ライトやカメラを動かすと、 氷と周りの照らされ方がそろって変わる

2. generateSDF: CPU で SDF を焼く                                   step2-bake-sdf.md
  [ ] 形の種類に Sdf を足し、 generateShape の switch から generateSDF を呼ぶ
  [ ] 角を丸めた箱の SDF を書く (まずはゆらぎ・欠けなし)
  [ ] 64 × 64 × 64 の格子 (マス目の真ん中) に焼く
  [ ] (先に見る: samples/02_sdf で距離の断面、 samples/05_baked_sdf で焼く流れ)
  [ ] 確かめる: 中心・外・表面の値をログに出し、 符号と大きさが合っている

3. 3D テクスチャを作って GPU へ送る                                  step3-sdf-texture.md
  [ ] 既定ヒープに 3D テクスチャ (R32_FLOAT) を作る
  [ ] GetCopyableFootprints の並びでアップロードバッファに書き、 CopyTextureRegion とバリアを記録する
  [ ] SRV を作り、 ルートシグネチャにテーブル (t0) と静的サンプラー (s0) を足す
  [ ] (先に見る: samples/05_baked_sdf の SdfTexture。 同じ手順だけを短く書いてある)
  [ ] 確かめる: RenderDoc でテクスチャの中身 (z の断面) が見える

4. 箱を描いて、 箱の中をレイマーチする (まずは不透明)               step4-raymarch.md
  [ ] 格子を覆う箱のメッシュを作り、 mGeom に入れる
  [ ] SDF 用のパイプライン (裏面だけ描く・深度に書かない) を作る
  [ ] シェーダー: 箱との交差 → 球追跡 → 法線 → 今の PBR で塗る。 当たらなければ discard
  [ ] (先に見る: samples/04_sdf_raymarch で球追跡の歩数と法線)
  [ ] 確かめる: 角の丸い塊が見える。 寄っても消えない。 箱の形が見えない

5. 氷の光学 (反射・屈折・吸収・全反射)                              step5-optics.md
  [ ] 透けた先の色の取り方を決める (空だけ / 不透明な物を描いた色のコピー)
  [ ] 表面: Fresnel で反射を足し、 屈折して中へ
  [ ] 中: 出口まで進み、 吸収する。 出口で屈折か全反射
  [ ] (先に見る: samples/03_raymarch で、 中を進んで吸収を足す形)
  [ ] セッター・ゲッター: 屈折率、 吸収の色
  [ ] 確かめる: 向こうがずれて見える。 厚い所が青い。 縁で映り込む

6. 表面のゆらぎと角の欠け (形を氷らしく)                            step2-bake-sdf.md の後半
  [ ] 値ノイズで表面を少し波打たせる
  [ ] なめらかな最大で角を 1 つ欠く
  [ ] 確かめる: 屈折の模様がゆがむ。 球追跡で穴が空かない (1 歩を 0.9 倍に)

7. 気泡 (芯の白い濁り)                                              step6-bubbles.md
  [ ] SDF の深さで芯だけに気泡の密度を置く
  [ ] 中を進む 1 歩ごとに、 散乱を足し、 遮られた分を減らす
  [ ] セッター・ゲッター: 気泡の密度
  [ ] 確かめる: 芯が白い。 密度 0 で澄む

8. 色付きの影                                                       step7-shadow.md
  [ ] エンジンの影の仕組みを調べる (シャドウマップがあるか)
  [ ] 床の点から太陽へ SDF を追い、 中を通った長さで太陽の光を減らす
  [ ] 確かめる: 薄い青の影が、 太陽と反対の側に落ちる

9. 調整と仕上げ                                                     step8-debug-tune.md
  [ ] デバッグ表示 (法線・歩数・SDF の断面) で怪しい所を見る
  [ ] 重さを測り、 格子の細かさ・歩数・区間の数を調整する
  [ ] 値 (屈折率・吸収の色・気泡) を決める
  [ ] 発表用の絵を撮る (docs/presentation/outline.txt)
