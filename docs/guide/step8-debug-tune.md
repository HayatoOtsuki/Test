# step8. デバッグと調整

絵がおかしいとき、 重いとき、 値を決めるときに見る。

---

## 1. デバッグ表示

シェーダーの最後の色を、 確かめたい値に置き換えて見る。 定数に 「表示の種類」 を 1 つ足し、 キーで切り替えられるようにしておくと便利。

| 表示 | 書き方 (例) | 見ること |
| --- | --- | --- |
| 法線 | `return float4(n * 0.5 + 0.5, 1);` | 面の向きがなめらかに変わるか。 上を向く面が緑っぽい (y が大きい) |
| 歩数 | `return float4(i / 128.0, 0, 0, 1);` | 赤いほど歩数が多い。 縁 (表面すれすれの光線) が赤いのは普通。 面の真ん中が赤いなら 1 歩が小さすぎる |
| 当たった距離 | `return float4(frac(tHit * 10).xxx, 1);` | 縞が等高線のように並ぶか。 途切れは穴 |
| SDF の断面 | 箱の中の水平な面で `SampleSdf` を読み、 正を赤・負を青、 0 の近くを白 | 形が焼いたとおりか。 縞 (`frac(φ × 20)`) で距離の傾きが一定か |
| 中を通った長さ | `return float4(len.xxx, 1);` | 厚い所ほど明るいか |

RenderDoc / PIX:

- **Pixel History** (画素の履歴): おかしい画素を選ぶと、 その画素に何がどの順で描かれたかが見える。
- **シェーダーのデバッグ**: 画素を選んでピクセルシェーダーを 1 行ずつ進められる (Debug ビルドの `D3DCOMPILE_DEBUG` でソースが見える)。
- **テクスチャの表示**: 3D テクスチャの z の断面を動かして中身を見る。

## 2. 症状から探す

| 症状 | まず見る所 |
| --- | --- |
| 何も出ない | step3 のヒープとテーブル、 step4 の `discard` の条件、 step1 のカメラの位置 |
| 黒い点・白い点 | NaN: `normalize(0)`、 `pow(負, …)`、 `sqrt(負)`、 `log(0)`。 `saturate` / `max` で守る |
| 表面に穴 | 球追跡の 1 歩 (0.9 を下げる)、 回数の上限 |
| 縞・層 | 3D テクスチャの写し方 (行の間隔)、 中を進む 1 歩が大きい |
| 屈折がおかしい | `refract` の法線の向きと比 (step5) |
| 色が暗い・白っぽい | 吸収の符号、 トーンマップとガンマを 2 回掛けていないか |
| ライトがずれる | 向きの約束、 行列の転置 (step1) |

## 3. 重さを測って調整する

GPU の時間を測る (PIX のタイミング、 またはタイムスタンプのクエリ)。 重い順に効く所:

| つまみ | 下げると | 気を付けること |
| --- | --- | --- |
| 画面の大きさ (氷が映る画素の数) | ほぼ比例して軽くなる | 氷を半分の解像度で描いて拡大する手もある |
| 区間の数 (`MAX_SEGMENTS`) | 全反射の多い所が軽くなる | 少なすぎると暗い点が増える |
| 中を進む歩数・上限 | 中の計算が軽くなる | 気泡の縞が出る |
| 球追跡の回数 | 縁が軽くなる | 縁に穴 |
| 格子の細かさ (64³) | メモリと読み出しが減る | 角の丸み・ゆらぎがつぶれる。 16 bit (`R16_FLOAT`) にしてもメモリは半分 |
| 法線の読み出し (6 回) | 4 回にする方法 (四面体の 4 点) もある | |

## 4. 値を決める

| 値 | 決め方 |
| --- | --- |
| 屈折率 | 氷は 1.31 (実測)。 変えると水 (1.33) やガラス (1.5) らしくなる |
| 吸収の色 | 本物は (0.76, 0.95, 0.997) / 1 m。 塊が小さいと色がほぼ見えないので、 見せたい色の濃さで決める |
| 気泡の密度 | 芯の白さで決める。 透明な氷 (業務用の氷) なら 0 |
| 気泡の深さの範囲 | 氷の大きさの 1/4〜1/2 くらいから芯 |
| ゆらぎの大きさ | 数 mm。 大きいと屈折の模様が派手になる |

## 5. 発表用の絵

`docs/presentation/outline.txt` の 「絵」 の欄に合わせて撮る。 比べる絵 (プリミティブ ↔ SDF、 気泡あり ↔ なし、 影なし ↔ あり) は、 カメラを動かさずに切り替えて撮ると分かりやすい。
