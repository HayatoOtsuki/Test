# step5. 氷の光学 (反射・屈折・吸収・全反射)

**ゴール**: SDF の氷が透明になる。 向こうがずれて見え、 厚い所が青く、 縁で空が映る。

計算の解説: [`docs/06-ice-optics.md`](../06-ice-optics.md)。 見本: `src/ice/shaders/IceSdf.hlsl` (`ShadeIceSdf`, `MarchInside`, `FresnelDielectric`)。

---

## 1. 透けた先の色の取り方を決める

屈折した光線が氷を出た後、 **その先に何が見えるか** を求める関数が要る (このリポジトリでは `Environment(ro, rd)`)。 自分のエンジンで使える物から選ぶ。

| やり方 | 中身 | 向いている時 |
| --- | --- | --- |
| A. 空だけ | 空のキューブマップ (環境マップ) を `rd` で読む | まず動かすとき。 いちばん簡単 |
| B. 不透明な物の色のコピー | 不透明な物を描き終えた画面をテクスチャにコピーし、 光線が出た点の少し先 (例: 0.5 m) を画面に投げて、 その画素を読む。 画面の外なら空 | 床や周りの物が氷越しに見えてほしいとき |
| C. 式で書いた景色 | このリポジトリのように、 床と空を式で書く | 見本と同じ絵で確かめたいとき |

**A で始めて、 動いてから B** にするのがおすすめ。 B の手順:

1. 不透明な物を描いた後、 氷を描く前に、 色のバッファをコピーする (エンジンにその段があれば使う)。
2. 氷のシェーダーで、 出た点 `p` から `p + rd × 0.5` を `ViewProj` で画面の座標に直す。
3. その座標でコピーを読む。 画面の外なら A の空にする。

## 2. 表面: 反射と屈折

```hlsl
float F0 = ((eta - 1) / (eta + 1))²;                 // 屈折率 1.31 なら 0.018
float F = F0 + (1 - F0) * pow(1 - saturate(dot(-rd, n)), 5);
col += thr * F * 景色(反射の向き);
thr *= 1 - F;
rd = refract(rd, n, 1.0 / eta);                       // 空気 → 氷
p -= n * 0.002;                                       // 少し中へ
```

- 表面から少しずらす (2 mm) のは、 同じ表面にすぐまた当たらないため。
- 今のプリミティブの PBR の `F0` (スペキュラから決める) とは別に、 氷は屈折率から決める。

## 3. 中: 出口まで進んで吸収

1. `MarchInside`: `clamp(−φ, 格子の半分, 5 cm)` ずつ進み、 φ > 0 になったら 2 分探索で出口を絞る。
2. 進んだ長さ `len` で吸収: `thr *= exp(−σa × len)`。
3. σa は CPU で吸収の色から求めて定数で渡す: `σa = −ln(色)` (厚さ 1 m を通った白の色)。

## 4. 出口: 屈折か全反射

```hlsl
float3 o = refract(rd, -n, eta);          // 氷 → 空気 (法線は中向き)
if (dot(o, o) < 1e-6) {                   // 全反射
    rd = reflect(rd, n);  p -= n * 0.002; // 中で跳ね返って続ける
} else {
    thr *= 1 - Fresnel(dot(o, n));
    rd = o;  p += n * 0.002;              // 外へ
    // また氷に当たるか (へこんだ形) → 当たれば 2. へ、 当たらなければ 景色(rd) を足して終わり
}
```

これを区間の上限 (8) まで繰り返す。 上限で出られなかった光は、 今の向きの景色で近似して足す (捨てると黒い点になる)。

## 5. セッター・ゲッター

`IceComponent` に足す (見本: `setRefractiveIndex`, `setAbsorptionColor`)。 範囲に収めてから入れる。

| 値 | 範囲 | 既定 |
| --- | --- | --- |
| 屈折率 | 1.0〜2.5 | 1.31 |
| 吸収の色 | 各 0.01〜1 (0 だと −ln が無限大) | (0.45, 0.75, 0.90)。 本物らしくするなら (0.76, 0.95, 0.997) |

## 確かめ方

- [ ] 氷越しの景色がずれて見える (A なら空、 B / C なら床)
- [ ] 正面はほとんど透け、 縁で空が映る
- [ ] 厚い所 (真ん中) ほど青い。 吸収の色を (1, 1, 1) にすると色が消える
- [ ] 側面を斜めに見ると、 向こうが見えない所がある (全反射)
- [ ] 屈折率を 1.0 にすると曲がらなくなる
- [ ] 黒い点が目立たない

## つまずきやすい所

| 症状 | 原因 |
| --- | --- |
| 中が真っ黒 | 出口の `refract` の法線 (`-n`) と比 (`eta`) が逆 |
| 逆に曲がる | 入るときの比が `eta` (正しくは `1 / eta`) |
| 表面にまだらな黒い点 | 表面からずらしていない (または小さすぎる) |
| 全体が白い・明るすぎる | 吸収の符号 (`exp(+…)`) / 反射を足した後に `thr` を減らしていない |
| B で縁がずれる・ちらつく | 投げる距離が長すぎる / 画面の外の扱いが無い |
