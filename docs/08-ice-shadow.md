# 08. 氷の色付きの影

床に落ちる氷の影を、 **太陽への光線が氷の中を通った長さ** で吸収して色付ける。 不透明な物の影は黒いが、 氷の影は光が通り抜けるので **薄く、 青い**。

この段の絵: SDF の氷の影が、 太陽と反対の側の床に、 薄い青で落ちる。 芯の気泡の所は少し濃い。 J / L で太陽を回すと影も回る。

---

## 1. やり方の選び方

| やり方 | 中身 | ここで選ばない理由 / 選ぶ理由 |
| --- | --- | --- |
| シャドウマップ | 太陽から見た深度を絵に描き、 床の点がそれより奥なら影 | 「どれだけ透けたか (色)」 が分からない (深度は 1 つの値) |
| 背景のシェーダーに氷を足す | エンジンの床のシェーダーが、 氷の SDF を読んで影を付ける | エンジンが氷のことを知ることになる (部品の分け方が崩れる) |
| **氷の部品が床を描き直す** (選んだ) | 氷の部品が、 影が落ちうる床の四角形を自分で描き、 SDF を太陽へ追って、 床の色を描き直す | 氷のことは氷の部品の中で閉じる。 SDF があるので、 中を通った長さがすぐ分かる |

> 自分のエンジンでは、 エンジンの影の仕組み (シャドウマップなど) に合わせる。 色付きの透過の影は、 「透過のシャドウマップ (通り抜けた割合を色で描く)」 などで作る。

## 2. 描く順番

```cpp
// IceImplement::draw3D (SDF の形のとき)
commandList->SetPipelineState(mShadowPipeline.Get());
commandList->DrawInstanced(6, 1, 0, 0);      // 1. 影 (床の四角形)
commandList->SetPipelineState(mSdfPipeline.Get());
commandList->DrawIndexedInstanced(...);       // 2. 氷 (箱の中をレイマーチ)
```

影を先に、 氷を後に描く。 氷は自分の画素を上から塗り、 氷に当たらない画素は捨てる (`discard`) ので、 そこには影の付いた床が見える。

## 3. 影が落ちうる床の四角形 (ShadowQuadCorner)

頂点バッファは使わず、 頂点の番号 0〜5 から三角形 2 枚の四角形を作る。

```hlsl
float h = max(bmax.y, 0.0);
float2 offset = -L.xz * (h / max(L.y, 0.05));
float2 lo = min(bmin.xz, bmin.xz + offset);
float2 hi = max(bmax.xz, bmax.xz + offset);
```

### 影の落ちる所の計算

高さ $h$ の点から、 太陽の向き $\mathbf{L}$ と逆へ進んで床 ($y = 0$) に着く所を求める。 点 $P$ から $-\mathbf{L}$ へ $s$ 進むと高さは $P_y - s L_y$。 これが 0 になるのは $s = P_y / L_y$。 そのときの水平のずれは

$$
\Delta_{xz} = -\mathbf{L}_{xz} \cdot \frac{h}{L_y}
$$

太陽が低い ($L_y$ が小さい) ほど、 影は長く伸びる。 0 で割らないよう、 $L_y$ は 0.05 で止める。

**箱の底面の四角** (影の根元) と、 **箱の上面を床へ落とした四角** (影の先) の両方を含む四角を作れば、 影はその中に必ず収まる。

| 頂点 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| u | 0 | 1 | 1 | 0 | 1 | 0 |
| v | 0 | 0 | 1 | 0 | 1 | 1 |

`lerp(lo, hi, (u, v))` で角の位置になる。 三角形は 0-1-2 と 3-4-5。 床を上から見ても下から見ても描けるよう、 カリングはしない。

## 4. 影の濃さ: 太陽へ SDF を追う (IceShadowTransmittance)

床の点 $P$ から太陽の向きへ光線を出し、 氷の中 ($\phi < 0$) を通った長さ $L_{in}$ と、 通った所の気泡の濃さの合計 $\tau_b$ を数える。

```hlsl
float d = SampleSdf(q);
float s = max(abs(d), VoxelSize * 0.5);
if (d < 0.0) {
    insideLength += s;
    bubbleDepth += BubbleDensityAt(q, -d) * s;
}
t += s;
```

| 点 | 理由 |
| --- | --- |
| 外では $\phi$、 中では $-\phi$ ずつ進む (`abs(d)`) | どちらも 「表面までの距離」 なので、 表面を越えない (外は球追跡、 中は前の段の MarchInside と同じ考え) |
| 下限は格子の半分 | 表面の近くで 1 歩が 0 に近づき、 止まってしまうのを防ぐ。 越えすぎは格子の半分まで |
| 長さを足すのは中にいる歩だけ | 中を通った長さ = 吸収する長さ |

### 通り抜ける割合

$$
T = 0.9 \cdot \exp\left(-\sigma_a L_{in} - \tau_b\right),\qquad \tau_b = \sum \sigma_b(q)\, s
$$

- $\exp(-\sigma_a L_{in})$: 氷の吸収 (Beer–Lambert)。 RGB ごとに違うので **影が青くなる** (赤がよく吸われる)。
- $\exp(-\tau_b)$: 気泡に遮られた分。 $\tau_b$ は **光学的な厚さ** (密度 × 長さの合計)。 芯を通る所の影が少し濃い。
- 0.9: 入るときと出るときの表面の反射 (正面から約 2% ずつ。 斜めはもっと多い) と、 屈折で光が曲がって散る分をまとめた近似。

> 本当は、 屈折で曲がった光が床の一部に集まって明るい模様 (コースティクス) ができる。 ここでは扱わない。

## 5. 床を描き直す (ShadeShadowedFloor)

背景の床と **同じ式** で色を作り直し、 太陽の光だけに $T$ を掛ける。

```hlsl
float3 T = IceShadowTransmittance(worldPos);
if (min(T.x, min(T.y, T.z)) >= 0.999) return false;   // 影が無い所は描かない
...
color = ToDisplay(ApplyFog(ShadeFloorLit(worldPos, T), toPoint / dist, dist));
```

エンジンの `Environment.hlsli` に、 太陽の届く割合を受け取る版を足した。

```hlsl
float3 ShadeFloorLit(float3 p, float3 sunVisibility)
{
    ...
    float3 sun = SunColor() * saturate(SunDirection().y) * sunVisibility;
    float3 ambient = float3(0.22, 0.30, 0.42);
    return albedo * (sun + ambient);
}
```

**なぜ掛け算のブレンド (暗くするだけ) にしないか**:

1. 影で減るのは **太陽の光だけ**。 空からの光 (`ambient`) は、 氷の周りから回り込んで届くので減らさない。 床の色全体に掛けると、 空の光まで減って影が濃すぎる。
2. 背景はトーンマップとガンマを掛けた後の色。 その後で掛け算すると、 明るさの比が光の強さの比とずれる (ガンマは掛け算と入れ替えられない)。

そこで、 光の強さの段階 (トーンマップの前) で太陽の光だけに $T$ を掛け、 霧・トーンマップ・ガンマを背景と同じ順に掛け直す。 影の外では背景とぴったり同じ色になる。

## 6. 確かめ方

| 項目 | どうなればよいか |
| --- | --- |
| 向き | 影が太陽と反対の側に落ちる。 J / L で太陽を回すと、 影も回る |
| 色 | 黒でなく薄い青。 吸収の色を変えると影の色も変わる |
| 気泡 | 気泡があると影の真ん中が少し濃い。 B で抜くと薄くなる |
| 境目 | 影の四角形の縁が見えない (影の外は背景と同じ色) |

## 7. つまずきやすい所

| 症状 | 原因と直し方 |
| --- | --- |
| 四角形の縁が見える | 描き直した床の色が背景とずれている (霧・トーンマップの順、 距離の取り方)。 影の外で `discard` しているか |
| 影が切れる | 四角形が小さい (上面を床へ落とした所を含めていない) |
| 影が逆の側に出る | 太陽の向きの約束 (面から太陽へ) と逆に使っている |
| 影が真っ黒・濃すぎる | 空の光にまで $T$ を掛けている / 吸収を 2 回掛けている |
| 氷の下が影にならない | 太陽への光線の始点が箱の外と判定されている (箱との交差の入口を 0 で止めているか) |

> 氷の中を通して見た床 (屈折した光線の先) には、 この影は付かない。 氷のシェーダーは背景の `Environment` を読むため。 付けるなら、 `Environment` の床の所で同じ `IceShadowTransmittance` を掛ける。
