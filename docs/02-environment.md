# 02. 背景 (空と床)

氷の向こうに見える物を用意する。 屈折で景色がずれて見えることが分かるように、 **市松模様の床** を置き、 太陽で照らす。

この段の絵: 青い空と、 遠くで霧に溶ける市松模様の床。

## どこで使うか

`src/engine/shaders/Environment.hlsli` の `Environment(ro, rd)` は、 2 か所から使う。

| 使う所 | 何に使うか |
| --- | --- |
| `Background.hlsl` (エンジン) | 画素ごとの光線の先の色 = 画面の背景 |
| 氷のシェーダー (`src/ice/shaders/`) | 氷で反射・屈折した光線の先の色 |

同じ関数なので、 **氷越しに見える床と、 氷の周りに見える床が同じ模様でつながる**。
自分のエンジンへ移すときは、 氷のシェーダーが呼ぶ `Environment` を、 エンジンの空 (キューブマップなど) や、 不透明な物を描いた色のコピーを読む関数に置き換える。

## 太陽

```hlsl
static const float3 SUN_COLOR = float3(1.0, 0.95, 0.88) * 1.8;

float3 SunDirection()
{
    return normalize(float3(-0.5, 0.45, -0.6));
}
```

- `SUN_COLOR`: 太陽の光の色と強さ。 白より少し黄色寄り。 強さは空の明るさとの釣り合いで決めた。
- `SunDirection`: 地面から太陽へ向かう向き。 高さは約 30° (`asin(0.45 / 0.9)`)。
  初めのカメラから見て奥にあるので、 氷は **逆光** になり、 影は手前に落ちる。 逆光は氷の透明さがいちばんよく見える向き。

## 空

```hlsl
float3 Sky(float3 rd)
{
    float3 horizon = float3(0.62, 0.72, 0.85);
    float3 zenith  = float3(0.16, 0.34, 0.70);
    float3 col = lerp(horizon, zenith, saturate(rd.y * 1.6));

    float s = max(dot(rd, SunDirection()), 0.0);
    return col + SUN_COLOR * (pow(s, 900.0) * 6.0 + pow(s, 10.0) * 0.12);
}
```

1. **グラデーション**: `rd.y` (光線の上向きの成分) で、 地平線の白っぽい青から天頂の濃い青へ補間する。
   `rd.y × 1.6` を 0〜1 に収めるので、 約 39° より上は同じ色。
2. **太陽**: `s` は光線と太陽の向きの cos。 1 に近いほど太陽に近い。
   - `pow(s, 900)`: 太陽の向きのごく近くだけで 1 に近くなる → **小さな円盤**。 氷の表面で反射すると鋭いきらめきになる。
   - `pow(s, 10)`: ゆるやかに下がる → **太陽の周りのぼんやりした明るさ**。
   - `max(…, 0)`: 太陽と反対の向きでは `s` が負になる。 `pow` に負の数を渡すと NaN になるので、 0 で止める。

## 床

```hlsl
float3 ShadeFloor(float3 p)
{
    float checker = frac((floor(p.x * 2.0) + floor(p.z * 2.0)) * 0.5) * 2.0;
    float3 albedo = lerp(float3(0.46, 0.44, 0.40), float3(0.22, 0.23, 0.26), checker);

    float3 sun = SUN_COLOR * saturate(SunDirection().y);
    float3 ambient = float3(0.22, 0.30, 0.42);
    return albedo * (sun + ambient);
}
```

### 市松模様

- `floor(p.x × 2)`: x を 50 cm ごとのマスの番号にする。 z も同じ。
- 2 つの番号の和が偶数か奇数かで色を変えると、 市松模様になる。
- `frac(n × 0.5) × 2` は、 `n` が偶数なら 0、 奇数なら 1。 `n` が負でも同じ答えになる
  (`fmod` は負の数で符号が変わるので使わない)。

### 照らし方

| 光 | 式 | 意味 |
| --- | --- | --- |
| 太陽 | `SUN_COLOR × SunDirection().y` | 床の法線は真上 (0, 1, 0) なので、 当たる強さ (法線と光の向きの cos) は太陽の向きの y 成分 |
| 空 | `ambient` | 空のあらゆる向きから来る光をまとめて、 一定の少し青い光とした |

色 (`albedo`) に光の和を掛けたものが、 床から目に届く光。

> この段の床には影が無い。 氷の影は、 氷の部品が自分で床に描く (`feature/ice-shadow`)。 エンジンの背景に氷のことを書かないため。

## 光線の先の色

```hlsl
float3 Environment(float3 ro, float3 rd)
{
    if (rd.y < 0.0) {
        float t = max(-ro.y / rd.y, 0.0);
        float3 col = ShadeFloor(ro + rd * t);
        float fog = 1.0 - exp(-t * 0.03);
        return lerp(col, Sky(rd), fog);
    }
    return Sky(rd);
}
```

1. **床に当たるか**: 光線 `ro + rd × t` の高さは `ro.y + rd.y × t`。 下を向いている (`rd.y < 0`) ときだけ床に届く。
2. **当たる距離**: 高さが 0 になる `t = -ro.y / rd.y`。
3. **床より下から出た光線**: 氷の底の面から下へ出た光線は、 出発点がわずかに床より下になることがある。
   そのとき `t` は負になるので、 `max(…, 0)` で 「その場で床に当たった」 ことにする。 これが無いと、 氷の底から空が見えてしまう。
4. **霧**: 遠くの床ほど空の色を混ぜる。 `t = 33 m` で約 63%。 地平線の近くで細かい模様がちらつくのも隠せる。

## 確かめ方

| 項目 | どうなればよいか |
| --- | --- |
| 床 | 50 cm 角の市松模様が、 太陽に照らされて見える |
| 霧 | 地平線の近くで床が空の色になじむ |
| 空 | 上ほど濃い青。 カメラを回すと、 太陽の側の空が少し明るい |
