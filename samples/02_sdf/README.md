# 02. SDF だけ

**SDF (符号付き距離場)** そのものを見るサンプル。 空間に 1 枚の **断面の板** を置き、 板の上の各点で 「形の表面までの距離」 を計算して色を塗る。
形の表面を探す (光線を進める) ことはしない。 SDF が 「空間の全部の点に数が入っている物」 だということを、 目で確かめる。

| キー | 動作 |
| --- | --- |
| 1〜8 | 形: 球 / 箱 / 角の丸い箱 / トーラス / 足す / 削る / なめらかに足す / 氷 (本体と同じ式) |
| ↑ ↓ | 板を動かす (5 cm ずつ) |
| P | 板の向き: 縦 (z が一定の面) ↔ 横 (y が一定の面) |

## 色の読み方

| 色 | 意味 |
| --- | --- |
| 暖色 (外) | φ > 0。 形の外。 遠いほど濃い |
| 青 (中) | φ < 0。 形の中。 深いほど濃い |
| 濃い線 | φ = 0。 **ここが形の表面** |
| 細い線 | 等高線。 0.05 m ごと |

**形とは、 濃い線 (φ = 0) の所のこと**。 地図に例えると、 海岸線 (高さ 0) が形の輪郭で、 等高線が陸の高さ (外の距離) と海の深さ (中の深さ) を表している。

試すこと:

1. 8 (氷) のまま ↑ ↓ で板を前後に動かす。 板が氷を通る所でだけ、 青い (中の) 部分が見える。 板を手前の角まで動かす (z = +0.30 くらい) と、 欠けた角の丸いへこみが見える。
2. P で横の板にして、 4 (トーラス) を見る。 ドーナツを輪切りにした、 2 つの円の間が青い。
3. 等高線の間隔を見る。 球・箱は、 どこでも同じ間隔 (= 本当の距離)。 削る (6) やなめらかに足す (7) は、 つなぎ目の近くで間隔がずれる (本当の距離ではなくなる。 後の 04 で球追跡の歩幅を控えめにする理由)。

## 形の式

### 球

$$\phi(p) = \lVert p - c \rVert - r$$

中心までの距離から半径を引くだけ。 中心では $-r$ (いちばん深い)、 表面で 0、 外へ行くほど増える。

### 箱 (半分の大きさ $\mathbf{b}$)

```hlsl
float3 q = abs(p) - b;
return length(max(q, 0.0)) + min(max(q.x, max(q.y, q.z)), 0.0);
```

- `abs(p)`: 箱は 3 つの軸について対称なので、 +x+y+z の 1/8 だけ考えればよい。
- `q`: 各軸で、 面からどれだけ外へ出ているか (負なら中)。
- 外: 出ている成分だけの長さ。 1 つだけ出ていれば面まで、 2 つなら辺まで、 3 つなら角までの距離になる。
- 中: いちばん近い面までの距離 = `q` のいちばん大きい成分 (0 に最も近い負の数)。

### 角の丸い箱

```hlsl
return sdBox(p, b - r) - r;
```

箱を半径 $r$ だけ小さくしてから、 表面を $r$ だけ外へふくらませる。 ふくらませると、 角は半径 $r$ の球の一部になって丸くなる。
**SDF では 「距離から引く」 = 「ふくらませる」** (2 の等高線を 1 本外へずらすのと同じ)。

### トーラス (ドーナツ)

```hlsl
float2 q = float2(length(p.xz) - R, p.y);
return length(q) - r;
```

点から 「輪 (半径 R の円) の上のいちばん近い点」 までの 2 次元の距離を作ると、 その平面ではただの円 (半径 r) の距離になる。

## 組み合わせ (CSG)

| 操作 | 式 | 意味 |
| --- | --- | --- |
| 足す | `min(a, b)` | 近い方の表面が、 合わせた形の表面 |
| 削る | `max(a, -b)` | 「A の中」 かつ 「B の外」 (B の符号を反転すると、 B の外が中になる) |
| なめらかに足す | `min(a, b) − k/4 · h²`、 $h = \max(k - \lvert a - b \rvert, 0) / k$ | 2 つが $k$ より近い所だけ少し小さくして、 境目を丸める |

メッシュで形を足したり削ったりするには、 三角形を切って貼り直す難しい計算が要る。 SDF なら **数を 1 つ比べるだけ**。

## 氷の形 (8)

本体の `IceGenerate.cpp` の `iceShapeSdf` と同じ作り:

1. 角の丸い箱
2. 上の角に球を置き、 なめらかに削る (角の欠け)
3. 値ノイズ (格子点の乱数をなめらかに補間した物) を 6 mm だけ足す (表面のゆらぎ)

本体は、 これを CPU で 64³ の格子に焼いて 3D テクスチャにしている (サンプル 05)。 このサンプルは同じ式をシェーダーで毎回計算している。

## SDF から読めること

| 読めること | どう読むか | 本体での使い道 |
| --- | --- | --- |
| 中か外か | φ の符号 | 光線が氷の中にいるか |
| 表面からの深さ | 中では −φ | 芯だけに気泡を置く (07) |
| 表面の向き (法線) | φ の勾配。 等高線に垂直な向き | 光の反射・屈折 (05, 06) |
| 表面まで安全に進める距離 | φ そのもの | 球追跡 (サンプル 04) |
